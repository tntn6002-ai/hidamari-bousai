ひだまりの防災

家の備えが“あと何日分”か、
ひと目でわかる。

  • 無料
  • スマホでかんたん
  • 位置情報なし

START

はじめ方は、3ステップ

  1. 1

    URLを開く

    スマホのブラウザ（Safari・Chrome どちらでも）で開きます。 hidamari-bousai.netlify.app

  2. 2

    メールで入る

    メールアドレスを入力 → 届いたメールのログインリンクをタップ。パスワードは不要です。

  3. 3

    世帯を作る

    「新しい世帯を作る」を選んで、名前を入れるだけ。あとは家の備蓄を登録していきます。

INSTALL

ホーム画面・Dockに置けば、アプリみたいに

  • iPhone / iPadSafariで開き、共有ボタン（□↑）→ 「ホーム画面に追加」
  • AndroidChromeのメニュー（⋮）→ 「アプリをインストール」
  • Mac・Safari「ファイル」→ 「Dockに追加」
  • Mac・Chromeアドレスバー右の インストールアイコン（⤓）、または ⋮ →「保存して共有」→「ページをインストール」

太陽アイコンをタップするだけで起動、ログイン状態も保たれます。
※ 先に「今すぐ開く」でアプリを開いてから追加してください（アイコンがアプリを起動します）。
※ ブラウザは Safari でも Chrome でもOK。呼び名が違うだけです（Safari＝「Dockに追加」／Chrome＝「インストール」）。
※ Mac で項目が押せないときは、スクリーンショットの編集画面を閉じ、ひだまりの画面をクリックして最前面にしてから試してください（プライベートウィンドウでは追加できません）。

FEATURES

できること

「何日分」が見える

水や食料が目標日数に足りているか、リングでひと目。

賞味期限アラート

期限が近づくと自動でお知らせ。買い替え忘れを防ぎます。

家ごとに管理

自宅・実家・職場など、拠点を分けて備蓄を管理。

買い足しもスムーズ

足りない物から、登録した商品リンクへ直行できます。

ハザードもすぐ確認

お住まいの地域の危険度マップを、その場でチェック。

家族で共有 / 各自で

家族は同じデータを共有、友人は自分専用の世帯で使えます。

楽しく続けられる

レベル・バッジ・防災クイズ（全50問）で、遊びながら家族みんなで備えられます。

友人と使っても、データは別々

友人に渡すのは このURLだけ でOK。友人は自分専用の世帯を作って使うので、あなたの家族のデータとは 完全に分かれます。位置情報も取得しません。

今すぐ開く

今日から、家族の備えを“見える化”。
